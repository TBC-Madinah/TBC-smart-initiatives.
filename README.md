# منصة التحليل المتكامل لأعمال الصيانة — TBC

منصة واحدة تجمع **الصيانة الوقائية (Maximo)** و**بلاغات الدعم الموحد** و**ملاحظات الاستشاري (SR)** و**الخطة الأساسية** و**خطة النظافة**، في القطاعات الثلاثة:
قطاع م. نورة الحربي · قطاع م. فيصل مسند · قطاع م. عبدالوهاب فلاتة. لا تتضمن أي جانب مالي أو غرامات.

## الصفحات
| الصفحة | المحتوى |
|---|---|
| الملخص التنفيذي | مؤشرات رئيسية، منحنى S، مقارنة القطاعات، استنتاجات تلقائية، أعلى المدارس أولوية |
| تحليل البلاغات | بلاغات الدعم الموحد فقط: الاتجاه الشهري والمتراكم، التخصص، الأولوية، أعمار المفتوح، خريطة حرارية |
| الوقائية والخطة | الالتزام بالخطة الأساسية: منحنيات S، التأخر، المقاولون، النطاقات، مطابقة الخطة مع Maximo |
| الكفاءة مقابل البلاغات | مصفوفة التزام كل مدرسة مقابل بلاغاتها، معامل الارتباط، أثر الوقائية المكتملة حسب التخصص |
| ملاحظات الاستشاري | الشدة، الأسباب الجذرية، الاتجاه، الحالة |
| خطة النظافة | تظهر عند وجود ملف خطة نظافة (يتعرف عليه النظام بمحتواه مهما كان اسمه) |
| المدارس | جدول كل المدارس + ملف تفصيلي لكل مدرسة |
| البيانات والإعدادات | الملفات المحمّلة، جودة المطابقة، هدف الالتزام وسماح التأخر |

زر **تقرير PDF** يفتح تقريراً من 10 صفحات A4 (غلاف، ملخص، وقائية، خطة أساسية، بلاغات، كفاءة، قطاعات، استشاري، مدارس الأولوية، منهجية) ثم «طباعة / حفظ PDF».

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى جذر المستودع (`index.html` و`.nojekyll` ومجلد `data`).
2. Settings ← Pages ← Branch: `main` / root.
3. لتحديث البيانات: استبدل الملفات داخل `data/` فقط (Commit). تقرأ المنصة الملفات عند كل فتح للصفحة، ويظهر وقت آخر تحديث من رأس `Last-Modified`.

### أسماء الملفات في `data/`
- `ppm.xlsx` — الصيانة الوقائية من Maximo
- `tickets.xlsx` — بلاغات الدعم الموحد
- `schools.xlsx` — قائمة المدارس (اختياري؛ عند غيابها تُستخدم القائمة المدمجة)
- أي ملفات أخرى (`sr.xlsx` الاستشاري، `plan.xlsx` الخطة الأساسية، خطة النظافة بأي اسم): على `github.io` تُكتشف تلقائياً من محتوى المجلد؛ وعلى أي استضافة أخرى أضف أسماءها في `data/files.json` مثل `["sr.xlsx","plan.xlsx"]`.

النظام يتعرف على نوع كل ملف **من أعمدته لا من اسمه**، ويقبل xlsx / xls / csv.

### خطة النظافة
القالب الثابت: من صفحة «البيانات والإعدادات» ← «تنزيل القالب» (الرقم الوزاري، اسم المدرسة، المدينة، اسم مقاول النظافة، تاريخ الزيارة، حالة الزيارة…). كذلك يُقبل الجدول التقويمي (عمود لكل تاريخ).

## ملاحظات
- «تحديث البيانات» (كلمة مرور) للمعاينة المحلية فقط: الرفع يظهر على هذا الجهاز ولا يُنشر للآخرين.
- المستودع العام يجعل ملفات `data/` مرئية للجميع؛ استخدم مستودعاً خاصاً إن كانت البيانات حساسة.
- الحسابات تتم بالكامل داخل المتصفح.
